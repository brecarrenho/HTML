Quais são as 3 formas de "ligar" o CSS no HTML?

O seletor é usado para "selecionar" os elementos HTML aos quais você deseja aplicar estilos.
Ele funciona como um localizador dos elementos na página web.
A propriedade é uma característica visual ou de layout do elemento que você deseja alterar.
É o tipo de estilo que será aplicado.
O valor especifica a configuração exata ou a aparência da propriedade.
É o que determina como a propriedade será exibida.
