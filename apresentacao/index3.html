Qual é a principal função dele? Faça uma analogia

-A principal função do CSS é controlar a aparência e o design visual de páginas web.
Ele descreve como os elementos HTML devem ser mostrados na tela, definindo cores, fontes, layouts, espaçamentos e outros estilos visuais.
-Pensamos em fazer a analogia com a decoração de uma casa, no qual o HTML seria a estrutura da casa crua
(paredes, telhado, portas, janelas), e o CSS seria a decoração/design, como a cor das paredes e o tipo de piso..
