Quais são as 3 formas de "ligar" o CSS no HTML?

"1- Inline: O estilo é aplicado diretamente em um elemento HTML específico usando o atributo style.
2- Interna: O código CSS é inserido na seção <head> do documento HTML, dentro da tag <style>. O estilo se aplica a toda a página.
3- Externa: O código CSS fica em um arquivo separado, com a extensão .css (ex: estilo.css), e é linkado ao documento HTML usando a tag <link> na seção <head>."
